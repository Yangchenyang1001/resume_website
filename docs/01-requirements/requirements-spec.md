## 1. 背景与目标

一个求职用的**单页简历站 + 项目详情页**，中文单语，纯静态。

它不承担投递职能（投递仍走 PDF 与招聘平台），唯一作用是：当面试官在简历里点到这个链接时，在 5 秒内相信「这个人能把 Agent / RAG 从 Demo 做到能上线」，并愿意点进详情页继续看。

成功标准（可验收）：

| # | 标准 | 验证方式 |
|---|---|---|
| S1 | 面试官不滚动即可获知「姓名 + 一句话定位 + 唯一技术标签 + 3 个项目入口」 | 1440×900 与 375×812 两档截图检查 |
| S2 | 详情页能让读者说清「这个 RAG 项目难在哪、他做了什么决策」 | 找一个不了解项目的同行读一遍后复述 |
| S3 | 可一键存为 PDF 并直接转给 HR，信息不缺章节 | `Ctrl+P` 导出后检查 |

## 2. 使用者与场景

| 角色 | 场景 | 关键约束 |
|---|---|---|
| 技术面试官（第一读者） | 简历筛选中，手机或桌面点开链接，停留 30–90 秒 | 首屏必须自证；弱网也要能读 |
| HR（第二读者） | 不打开网站，只接收面试官转的 PDF | 打印样式必须完整 |
| 本人（维护者） | 在 GitHub 网页端改内容并 commit，不装本地环境 | 内容与视图彻底分离 |
| 本人（面试中） | 口头引导对方看某一页某一节 | 需要稳定、可预测的 URL |

## 3. 范围

### 3.1 本期范围（In）

单页首页（首屏 / 项目卡片 / 经历时间线 / 联系方式）+ 1 个项目详情页 + 打印样式 + GitHub Pages 部署 + 内容层（JSON / Markdown 驱动）。

### 3.2 明确不做（Out）

| 不做 | 理由 |
|---|---|
| 内置编辑器 / 后台 / 数据库 | 复杂度不值；GitHub 网页端即免费 CMS |
| 联系表单 | 无后端，且投递不走网站 |
| 多语言 | 目标市场单一，双语稀释信息密度 |
| 暗黑模式 | 与「纸面文档感」基调冲突，且翻倍维护成本 |
| 装饰性动效（视差 / 全屏转场 / 自动轮播 / 数字滚动计数） | 抢注意力，与「5 秒扫读」冲突；见 §5 N3、N5 |
| 独立 blog / 文章系统 | 现有 blog 已停滞，v1 不合并 |
| 常驻在线 demo | 模型 API 成本高；挂掉的 demo 比没有更伤 |
| SEO 优化 | 站点 `noindex`，不参与搜索 |
| 自定义埋点与日志系统 | 越出「简历站」范围；访问统计走 §4.11 预留方案 |

## 4. 功能需求

### 4.0 页面与路由（P0）

路径固定，不含查询参数；目录式详情页（`/projects/<slug>/`），保证 URL 长期稳定、可口头指路。

| 路径 | 页面 | 本期 |
|---|---|---|
| `/` | 首页（单页，四区：首屏 / 项目卡片 / 经历时间线 / 联系方式） | P0，必建 |
| `/projects/rag/` | RAG 项目详情页 | P0，必建 |
| `/404.html` | 404 页 | P0，必建 |
| `/robots.txt` | 全站禁抓 | P0，必建 |
| `/projects/data-agent/` | 问数项目详情页 | P1 预留，不建目录 |
| `/stats/` | 访问统计页 | P2 预留，不建目录 |

验收标准：

- [ ] 上述 4 个 P0 路径部署后逐一可访问，实际路径与本表逐字一致
- [ ] 未建目录不在任何页面产生链接（§4.5-3）

### P0 · 首版必须（工期目标 3 天）

#### 4.1 首屏 5 秒区

- 内容：姓名、一句话定位、标签句、3 个项目入口、联系方式
- 验收标准：
  - [ ] 1440×900 与 375×812 下，不滚动即可见上述全部要素
  - [ ] 标签句全站**只出现一次**，不出现在详情页与页脚
  - [ ] 首屏出现的独立技术名词 ≤ 8 个，且必须落在一句话或项目卡片标签内，不得以并列标签墙形式呈现

#### 4.2 项目卡片 × 3

- 每卡：标题 / 角色 / 技术栈 / 一个量化结果 / 进入详情
- 验收标准：
  - [ ] 三卡外框等高（同一栅格行内），标题两行时正文整体下移，但不撑高卡片外框
  - [ ] 三卡顶端与底部对齐，高度差为 0
  - [ ] 首页只出现具备量化结果的项目；无量化结果的项目不上首页
  - [ ] 卡片整体可点击，不只标题可点

#### 4.3 经历时间线

- 验收标准：
  - [ ] 倒序，每条含公司 / 角色 / 时间区间 / 职责描述
  - [ ] 每条职责描述 60–90 字（按字数验收，不按行数——行数随视口与字号变化，不可验收）
  - [ ] 讲清「Java → Agent」的迁移，可迁移能力可被读出
  - [ ] 公司内部项目不附链接、不伪造仓库，只写职责 + 技术栈 + 脱敏量化
  - [ ] 375px 下折叠为单列，时间区间不折断换行

#### 4.4 项目详情页 × 1（RAG）

- 七段结构：背景与问题 / 架构图 / 关键工程决策 / 量化结果 / 已知不足 / 复现方式 / 演示录屏
- 验收标准：
  - [ ] 七段齐全，缺任一段视为未完成
  - [ ] 「关键工程决策」每条**必须写代价**，只写收益判为不合格
  - [ ] 「已知不足」≥ 3 条，且其中**至少 1 条为架构级取舍**，格式为「选了 X，代价是 Y」
  - [ ] 量化表至少含：RAGAS 指标、P95 检索延迟、P95 生成延迟、单次问答 token 成本、文档 / chunk 规模
  - [ ] 上述任一项确实无法测得时，须在「已知不足」写明原因与替代指标；**不允许留空，也不允许填写估算值冒充实测**

#### 4.5 内容层（内容与视图分离）

- 验收标准：
  - [ ] 构建产物的首页与详情页**正文区**不出现展示性文案字面量（标题、简介、项目描述）；页脚、404、打印页眉等固定字符串不受此限
  - [ ] 只改 `data/*.json` 或 `content/projects/*.md` 并重新构建，页面即随之变化，无需碰模板
  - [ ] 新增一个项目 = 追加一条数据 + 一个 md 文件，模板零改动
  - [ ] 未建目录不产生链接，导航与页脚不出现空壳入口

#### 4.6 打印样式表

- 验收标准：
  - [ ] `Ctrl+P` 时不出现导航、按钮、动效残留
  - [ ] 卡片与表格不被跨页切断
  - [ ] 仅对 `http` / `https` 外链，将 URL 以括号形式打印在链接文本后；内部锚点与站内路由不打印 URL
  - [ ] 打印内容与屏幕版信息一致，不缺章节

#### 4.7 部署

- 验收标准：
  - [ ] 推送 `main` 后，§4.0 中 4 个 P0 路径逐一可访问，实际路径与表内逐字一致
  - [ ] 全站 `noindex` + `robots.txt`，搜索引擎不收录

### P2 · 预留，本期不实现

#### 4.11 访问统计页（维护者自用 · 孤立页）

| 项 | 内容 |
|---|---|
| 定位 | 维护者自用查看访问量，不面向访客与面试官，不承担求职叙事 |
| 路由 | `/stats/`，已列入 §4.0，本期不建目录 |
| 选型（已定，见 D16） | 方案 A：第三方无 cookie 聚合统计 + 公开只读 JSON；禁止前端持特权 token |
| 本期动作 | 不建页面、不接统计脚本；先用服务商自带后台看数 |
| 触发条件 | 上线满一周且确认需要站内视图时再实现 |
| 口径 | 只统计页面访问（PV / UV），**不含 HTTP 请求数**——静态托管下无法获取 |

实现时须满足的验收标准（记录备用，本期不验收）：

- [ ] 页面明示口径为「页面访问」而非「请求数」
- [ ] 无数据时显示「暂无数据」，接口失败显示「统计暂不可用」，页面不崩
- [ ] `noindex`，不在导航、页脚、sitemap 出现
- [ ] 数据来源失败不影响任何其他页面
- [ ] 不返回、不展示原始 IP 与完整 UA

## 5. 非功能需求

| # | 需求 | 验收标准 |
|---|---|---|
| N1 | 内容不依赖 JS | **首页与项目详情页**禁用 JS 后信息零缺失、版式不塌；统计页不在此列 |
| N2 | 首屏直出 | 首屏文本在 HTML 中直出，不依赖 JS 渲染；CSS 单文件 ≤ 12KB（未压缩）时，文本可见先于样式加载完成 |
| N3 | 动效约束 | 全站 ≤ 300ms；只动 `opacity` / `transform` / `clip-path` / `stroke-dashoffset`；`prefers-reduced-motion` 全关；入场 ≤ 5 处、滚动触发 ≤ 3 处 |
| N4 | 资源预算 | CSS ≤ 12KB、JS ≤ 4KB，**均为单文件、未压缩、未 gzip 的原始字节**；无第三方库、无 Web Font |
| N5 | 视觉克制 | 色板 ≤ 3 主色 + 中性灰阶；无渐变背景、无 `box-shadow`、无玻璃拟态；字体层级 ≤ 5 级 |
| N6 | 移动可用 | 375px 起无横向滚动，点击目标 ≥ 40px |
| N7 | 可维护 | 维护者仅凭 GitHub 网页端即可完成内容更新 |
| N8 | 隐私 | 无 cookie、无第三方追踪脚本 |
| N9 | 打印 | `@media print` 关闭全部动画与装饰，保留信息层级 |

## 7. 决策记录（ADR）

| # | 决策 | 结论 |
|---|---|---|
| D4 | 技术栈 | 纯 HTML/CSS + 原生 JS，零依赖零打包 |
