本文档只记录两件事：你要学什么、你要动手做什么。

## 一、需要你学习的知识

| # | 知识点 | 一句话说清是什么 | 怎样算学到 |
|---|---|---|---|
| C1 | 构建 | 你改的是数据和 md，线上是构建产物，两者不是同一批文件 | 能说出「改一个 md 到线上可见」的完整步骤 |
| C2 | 内容与视图分离 | 页面结构固定，内容全部来自数据文件 | 能说明为什么加项目只改数据、不动页面 |
| C3 | 静态托管 | 托管平台直接发文件，没有服务器也没有运维 | 能说明为什么不买服务器、每月花多少钱 |
| C4 | 域名与 DNS | 域名靠一条 CNAME 记录指向托管地址 | 能说明解析没生效时页面是什么表现 |
| C5 | 打印样式 | 同一份页面，打印时套用另一套样式 | 能说明 `Ctrl+P` 为什么能得到可直接交付的 PDF |
| C6 | 渐进增强 | 内容先到达，动效后加载；脚本失败不影响阅读 | 能说明脚本被拦截时页面还能不能读 |

## 二、需要你介入的操作

| # | 操作 | 在哪做 | 怎么做 | 耗时 | 卡点 |
|---|---|---|---|---|---|
| O1 | 建仓库，可见性选 **public** | GitHub 网页端 | 新建 `resume_website` | 5min | 选 private 后 Pages 需付费账户 |
| O2 | Pages 源设为 **GitHub Actions** | Settings → Pages | Source 下拉选 GitHub Actions | 2min | 默认是 Deploy from a branch，不改则推送不生效 |
| O3 | 跑通首次部署 | Actions 页签 | 等流水线变绿 | 20min | 仓库 Actions 权限被默认收紧 |
| O4 | 填 `docs/02-design/inputs.env` | 任意编辑器 | 按 key 填右侧 value | 1–2h | 量化指标要跑实验才有，可能拖住详情页 |
| O5 | 备素材：录屏 3 分钟、架构图、指标表、README | 本地 + 你的 RAG 项目 | — | **6–10h** | 全项目最大时间块 |
| O6 | 域名（可选） | 域名商 + DNS 控制台 | 购买 → 实名 → 加 CNAME → Pages 填域名 | 1h + 等待 | 解析 10min–24h；证书签发前无 HTTPS |
| O7 | 上线自检 | 手机 + 浏览器 | 手机打开、`Ctrl+P`、禁用 JS 各看一遍 | 30min | 桌面正常、手机上横向滚动 |

顺序：O1 → O2 → O3 不可颠倒，O3 不通则站点无法上线。O4、O5 可与 O3 并行，O6 可延后到上线之后。
