## 1. 页面清单

| 页 | 路径 | 目的 | 主要角色 | 本期 | `.pen` 文件（`03-model/pen/`） |
|---|---|---|---|---|---|
| P1 首页 | `/` | 5 秒内自证 + 提供 3 个项目入口 | 技术面试官 | P0 | `home-pc.pen`（桌面）、`home-mobile.pen`（移动） |
| P2 详情页 | `/projects/<slug>/` | 讲清一个项目难在哪、做了什么决策 | 技术面试官 | P0（当前 slug = `rag`） | `detail-pc.pen` |
| P3 404 | `/404.html` | 兜住错链与未建路由 | 任何访客 | P0 | `404-mobile.pen` |
| P4 打印视图 | 上述任意页 `Ctrl+P` | 生成可转给 HR 的 PDF | HR | P0 | `print-home-pc.pen` |

**页面数与文件数不相等**：4 个页面 → 5 个文件，因为 P1 首页有桌面与移动两个断点各出一张画板。

命名格式 `<页面>[-<模块>]-<形态>.pen`，三段各管一件事：

| 段 | 取值 | 管什么 |
|---|---|---|
| 页面 | `home` / `detail` / `404` / `print` | 对应 §1 的 `P1`–`P4`，不带序号，避免与页面编号抢位 |
| 模块（可选） | `home` | 只在「某页的另一种呈现」需要标明原型页时写，如打印视图 `print-home-pc` |
| 形态 | `pc` / `mobile` | 固定映射 `pc`=1440、`mobile`=375；**像素宽度不进文件名**——它是形态的派生值，写进名字会与形态重复，且同页面同形态的两个状态（如有数据 / 空态）无法靠宽度区分 |

生成器会校验文件名末段形态与画板 `width` 是否一致，不一致直接报错，因此「文件名说 pc、画布却是 375」这类错误不可能进仓库。

P4 不是独立页面，是 P1/P2 的另一种呈现，**不新增区块**，只隐藏区块（见 §5.3）。

## 2. 主流程跳转图

```
入口（简历里的链接 / 直接访问）
   │
   ├─▶ P1 首页 ──点击任一卡片(A2)──▶ P2 详情页 ──点击「返回」(B1)──▶ P1
   │        │                              │
   │        │                              └─点击录屏(B8)──▶ 外部站点（新窗口）
   │        │
   │        └─点击联系方式(A1/A4)──▶ mailto: 或外部主页（新窗口）
   │
   └─▶ 未知路径（含 /projects/不存在的slug/）──▶ P3 404 ──点击返回(C2)──▶ P1

任意页面 Ctrl+P ──▶ P4 打印视图（隐藏 N1 导航、页脚按钮、所有外链跳转，保留信息）
```

分支与回退要点：

- P2 只有一条站内出口（B1 返回首页）。详情页之间**不互链**——本期只有 1 个详情页，多页互链会在 N 增长后变成维护负担。
- P3 只有一条出口（C2 返回首页），不做自动跳转（架构 §4.2 不做重定向）。
- 外链一律新窗口打开，站内链接本窗口。这是「访客读简历不丢当前位置」的唯一需要，不涉及视觉。

## 4. 区块说明表

「数据来源」列必须能在 `03-model/data-model.md` 找到字段；标「固定」的表示构建期决定的字符串或模板结构，不来自数据。

### 4.1 公共区块

错误态只有三种处置：**不渲染该区块** / **用占位文本** / **构建摘要提示（不阻断）**。除 `site.title`、`site.baseUrl` 缺失（站点级不可用）外，一律不阻断构建——单人维护的内容站，宁可先发出去再改（`03-model/data-model.md` §6 P-5）。

| 区块 | 名称 | 展示内容 | 数据来源字段 | 空态 | 错误态 |
|---|---|---|---|---|---|
| N1 | 站点导航 | 站名 + 站内链接（首页 / 已发布详情页） | `site.title`；链接由已发布 project 的 `slug` 与 `title` 生成 | 无已发布项目时只渲染站名 | 站名缺失 → 占位文本「【待填：站点名】」 |
| F1 | 页脚 | 站名、联系方式、年份 | `site.title`、`contacts[]`、构建期年份 | `contacts` 为空时只渲染站名与年份 | 无 |

### 4.2 P1 首页

| 区块 | 名称 | 展示内容 | 数据来源字段 | 空态 | 错误态 |
|---|---|---|---|---|---|
| A1 | 首屏区 | 姓名、定位句、技术标签、项目入口（当前 3 个）、联系方式 | `profile.name`、`site.tagline`、`site.techTag`、已发布 project 的 `title` + `slug`、`contacts[]` | 已发布项目为 0 时，入口行只显示联系方式，不留空框 | `tagline` 缺失 → 该行不渲染；超长只提示，靠 CSS 截断（视觉在 D 阶段） |
| A2 | 项目卡片区 | 每卡：标题、角色、技术栈、量化结果；整卡可点 | `project.title` / `.role` / `.stack` / `.highlight` / `.slug`（仅 `highlight` 非 null 的项目） | 0 张卡片 → 整区不渲染（不显示「暂无项目」） | **卡片数不设上限**，有几个渲染几个；标题过长靠两行截断，不减卡片 |

### 4.3 P2 详情页

| 区块 | 名称 | 展示内容 | 数据来源字段 | 空态 | 错误态 |
|---|---|---|---|---|---|

## 5. 交互约定

只写「发生什么」，不写视觉与动效细节。

### 5.1 点击

| 元素 | 行为 | 结果 |
|---|---|---|
| A1 项目入口 / A2 整卡 | 本窗口跳转 | 进入 P2；整卡可点，不只在标题上挂链接（spec §4.2-4） |
| A1 / A4 / F1 联系方式 | 邮箱 → `mailto:`；`http(s)` → 新窗口 | 不离开当前页；`wechat` 不可点 |
| N1 站内链接 | 本窗口跳转 | 首页链接带尾斜杠，避免 Pages 多余 301（架构 §4.2） |
| B1 返回首页 | 本窗口跳转 | 回 P1，回到顶部（不做锚点记忆，无 JS 也成立） |
| B7 / B8 外链 | 新窗口 | 保留当前页 |
| C2 返回首页 | 本窗口跳转 | 回 P1 |
| 页脚年份 | 不可点 | — |

### 5.2 提交与表单

无表单、无提交、无输入控件。本站没有任何写操作，因此也没有「提交失败」「校验不通过」的交互态——这是 spec §3.2 明确不做的部分。

### 5.3 打印（P4）

`Ctrl+P` 后：

| 区块 | 打印时 | 依据 |
|---|---|---|
| N1 导航、B1「返回首页」、C2 出口区 | 隐藏 | spec §4.6-1 |
| A1–A4、B1 标题头、B2–B8、F1 | 保留，信息不缺章节 | spec §4.6-4 |
| 卡片、表格 | 禁止跨页切断 | spec §4.6-2 |
| `http(s)` 外链 | 链接文本后以括号打印 URL | spec §4.6-3 |
| 内部锚点、站内路由、`mailto:` | 不打印 URL | spec §4.6-3 |
| 所有动效与装饰 | 关闭 | spec N9 |

### 5.4 脚本缺失 / 弱网

- JS 被拦截或加载失败：内容与链接全部可用，仅少入场动效（spec N1、架构 §4.2）。
- 首屏文本随 HTML 到达，不等待 CSS 与 JS（spec N2）。
